Hardware Profiling & Latency Calibration Tool (cmp-calibrate)

cmp-calibrate is an automated hardware diagnostic and latency qualification CLI tool designed to inspect the underlying host machine, measure real-world latency jitter, benchmark inter-core cache bouncing, and generate a calibrated production configuration (cmp-config.toml).

1. Installation & Usage​

Build the standalone calibration binary:

cargo build --release --bin cmp-calibrate
./target/release/cmp-calibrate --help

Commands:​

# Run full calibration suite and generate cmp-config.toml
./target/release/cmp-calibrate full --output cmp-config.toml

# Emit structured JSON for automated CI/CD qualification
./target/release/cmp-calibrate full --json

# Measure cross-core cache line bouncing latency
./target/release/cmp-calibrate core-latency

# Measure OS scheduling and hypervisor steal-time jitter
./target/release/cmp-calibrate jitter

# Benchmark Time Stamp Counter (rdtsc) read overhead
./target/release/cmp-calibrate tsc

# Benchmark shared memory throughput
./target/release/cmp-calibrate shm

3. Auto-Generated cmp-config.toml​

When executed with cmp-calibrate full, the tool generates a configuration file tailored to the host:

# ==============================================================================
# Chain-Market-Price Calibrated Configuration
# Auto-generated by 'cmp-calibrate'
# Host Qualification Grade: A+ (Institutional HFT Colocation)
# ==============================================================================

[hardware]
detected_tier = "Tier3EnterpriseBareMetal"
recommended_tier = "Tier3EnterpriseBareMetal"
logical_cores = 16
physical_cores = 16
hypervisor = "BareMetal(None)"

[sync]
wait_strategy = "BusySpin"
spin_limit = 256
yield_limit = 1024
enable_burst_promotion = true

[shm]
ring_slots = 65536
slot_size_bytes = 64
backend_policy = "CascadeFallback"

[telemetry]
rdtsc_overhead_ns = 8.12
core_ping_pong_p50_ns = 24.30
max_scheduler_jitter_us = 1.20
